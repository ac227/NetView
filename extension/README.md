# NetView 浏览器插件（Chrome / Edge）

浏览网页时一键把图片、视频、链接收藏到 NetView。

## 安装（开发者模式加载）

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录（`extension/`）

## 使用

### 右键菜单（最常用）
- 在任意**图片**上右键 → **保存图片到 NetView**（存链接）/ **下载原图到 NetView**（把图片文件真正保存下来）
- 在**视频/音频**上右键 → **保存视频/媒体到 NetView**
- 在**链接**上右键 → **保存此链接到 NetView**
- 在**页面空白处**右键 → **保存当前页面到 NetView**

### 工具栏弹窗
点击浏览器工具栏的 NetView 图标：
- 一键「保存当前页面」
- 扫描当前页所有图片，逐张「保存」（存链接）或「原图」（下载文件）

## 首次配置

打开扩展的**选项页**（右键扩展图标 → 选项，或 `chrome://extensions` 里点「详细信息」→ 扩展程序选项）：

1. 填 **服务器地址**：如 `http://localhost:8080` 或 `http://192.168.1.10:8080`（局域网）
2. 填 **访问密码**：NetView 的登录密码
3. 点「测试连接」，显示「连接正常」即可

## 说明

- 插件通过 NetView 的公开 API 通信，密码只存在浏览器本地（`chrome.storage`），不会上传到别处
- 「保存链接」= 在媒体库里记下来源链接，之后可在 NetView 里一键下载到本地
- 「下载原图」= 立即抓取图片字节并上传，NetView 自动生成缩略图
- 部分站点禁止跨域抓取原图时，会提示改用「保存链接」
